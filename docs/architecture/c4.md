# C4 model

This is the standalone product view. ByteDesk Platform is one external
consumer, not a container inside Agent Delivery.

## C1 — System context

```mermaid
flowchart LR
  Author[Agent author or catalog maintainer]
  Catalog[Definition-only Agent Catalog\nGit repository]
  Delivery[ByteDesk Agent Delivery\nheadless supply-chain and delivery control plane]
  Registry[OCI Registry]
  KMS[KMS and workload federation]
  Consumer[Consuming Platform]
  Host[Target-scoped Runtime Reconciler]
  Harness[Agent Harness\nHermes, OpenClaw, or other]
  Operator[Consumer operator or automation]

  Author -->|reviews portable Agent Spec and skills| Catalog
  Delivery -->|reads exact commit| Catalog
  Delivery -->|publishes and verifies exact digests| Registry
  Delivery -->|signs with purpose-bound identity| KMS
  Consumer -->|installation, current authority digests, desired target| Delivery
  Operator -->|API or CLI| Delivery
  Host -->|reads desired, appends observation| Delivery
  Host -->|pulls by digest| Registry
  Host -->|stages and activates verified content| Harness
```

```mermaid
flowchart TB
  API[API and action resources]

  Core[Delivery application\ninstallations, promotion, receipts]

  Trust[Trust and attestation verifier]
  Store[(Control-plane store)]
  Queue[(Durable work and outbox)]
  ConsumerAdapter[Consumer Adapter port]
  HostProtocol[Runtime reconciler protocol]

  CLI --> API
  API --> Core
  Core --> CatalogClient
  Core --> Validator
  Core --> Renderer
  Core --> OCI
  Core --> Trust
  Core --> Store
  Core --> Queue
  Core <--> ConsumerAdapter
  Core <--> HostProtocol
```

V1 is deployed as a modular monolith plus durable store/work execution. The
logical container boundaries do not imply independent microservices.

## Relationships deliberately absent

- Catalog packages do not call MCP servers or secret stores.
- Agent Delivery does not issue human or agent workload tokens.
- Agent Delivery does not own conversations, goals, tasks, or execution queues.
- A host reconciler does not receive human administration or agent capability
  permissions.
- Harnesses do not pull mutable catalog Git content.
